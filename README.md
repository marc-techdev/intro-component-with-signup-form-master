# Frontend Mentor - Intro Component With Signup Form

This is a solution to the **Intro Component With Signup Form** challenge from [Frontend Mentor](https://www.frontendmentor.io).

## Overview

A responsive intro section with a signup form and basic client-side validation. The goal is to closely match the provided design and handle form errors correctly.

## Features
- Form validation with custom error messages
- Email format validation

## Built With

- HTML5  
- CSS Tailwind
- JavaScript
